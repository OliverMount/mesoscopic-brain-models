# Mesoscopic-brain-models

This repository holds a collection of interactive demonstrations for exploring neural mass and mesoscopic brain models through Streamlit.

The applications here  are intended primarily as **interactive demonstrations and computational experiments** rather than as standalone software packages.

##### Demo 1: Classical Jansen–Rit Neural Mass Model

An interactive **Streamlit demonstration** of the classical **Jansen–Rit neural mass model** of a cortical column^[1].

**Link**: ![]()
 
**What You Can Do:**  
1. set the model parameters and explore their effects on cortical population output.
2. reproduce results associated with the original Jansen–Rit (1995) model and compare the simulation with reference results.
