# Mesoscopic-brain-models

Interactive demonstrations of mesoscopic brain models using Streamlit.

This repository will hold a collection of interactive demonstrations for exploring neural mass and mesoscopic brain models through Streamlit.

##### Demo 1: Classical Jansen–Rit Neural Mass Model

An interactive **Streamlit demonstration** of the classical **Jansen–Rit neural mass model** of a cortical column.

**Link**: ![]()
 
**What You Can Do:**  
1. set the model parameters and explore their effects on cortical population output.
2. reproduce results associated with the original Jansen–Rit (1995) model and compare the simulation with reference results.

The demonstrations are intended to provide an interactive way to **play with the models, examine their behavior, and develop an intuition for how the model parameters shape neural population dynamics**.


##### Demo 2: Synapse-driven Formulation of Jansen–Rit Neural Mass Model

 
The applications are intended primarily as **interactive demonstrations and computational experiments** rather than as standalone software packages.
